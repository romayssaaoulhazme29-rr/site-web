# Association des Jeunes Al Kendi (AJK)

Site officiel de l’**Association des Jeunes Al Kendi (AJK)** du BTS Al Kendi.  
Ce projet présente l’association, ses activités, les filières, ainsi qu’un espace de contact moderne et responsive.

---

## Aperçu

Ce site web a été développé avec :

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Express.js

Le projet offre une interface simple, moderne et attractive adaptée aux étudiants et visiteurs.

---

## Fonctionnalités

- Présentation de l’association
- Présentation des filières
- Interface responsive
- Section contact
- Design moderne et fluide
- Animations avec Motion

---

## Installation

### 1. Cloner le projet

```bash
git clone https://github.com/votre-utilisateur/association-des-jeunes-al-kendi.git
```

### 2. Accéder au dossier

```bash
cd association-des-jeunes-al-kendi
```

### 3. Installer les dépendances

```bash
npm install
```

---

## Lancer le projet en développement

```bash
npm run dev
```

Le site sera disponible sur :

```bash
http://localhost:5173
```

---

## Build du projet

```bash
npm run build
```
